# datacp.ar/datos-abiertos

> Plataforma que permite el acceso a datos electorales mediante exploración, análisis y visualización. Publica Pablo Cerchia de la Facultad de Ciencias Sociales de la Universidad de Buenos Aires de la carrera de Ciencia Política. Contiene acceso abierto y gratuito a una amplia variedad de datos de las elecciones presidenciales y legislativas nacionales ya procesados y estandarizados para consultar y descargar.

| Campo | Detalle |

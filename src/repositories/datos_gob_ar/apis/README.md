# datos.gob.ar/apis

> Plataforma de datos públicos en formatos abiertos desarrollado por Andino con CKAN que contiene APIs relacionadas a Resultados electorales, Presupuesto Abierto, Georeferenciales y Series de Tiempo.

---

## Información general

| Campo | Detalle |
|---|---|
| **Organismo** | Ministerio del Interior de la Nación / Dirección Nacional Electoral |
| **Tipo** | `API REST` |
| **Formato** | YAML |
| **Actualización** | Sin especificar |
| **Cobertura temporal** | Desde septiembre de 2023 hasta septiembre de 2023 |
| **Cobertura geográfica** | Nacional |
| **Licencia** | Datos abiertos |
